# `configs` 文件夹说明

`configs` 是项目配置文件目录。

## 主要作用

- 保存模型类别名称。
- 保存 YOLOv5 数据集配置。
- 保存 COCO 类别文件等参考配置。

## 主要文件

```text
configs/
  classes.txt
  coco_classes.txt
  powerline_data.yaml
  powerline_data_abs.yaml
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `classes.txt` | 当前输电线路模型的类别名称文件 |
| `coco_classes.txt` | COCO 数据集类别参考文件 |
| `powerline_data.yaml` | YOLOv5 训练用数据集配置，使用相对路径 |
| `powerline_data_abs.yaml` | YOLOv5 训练用数据集配置，使用绝对路径 |

## 当前模型类别

`classes.txt` 中共有 3 类：

```text
crane
excavator
foreign_object
```

对应中文含义：

| 英文类别 | 中文含义 | 风险等级 |
|---|---|---|
| `crane` | 吊车闯入 | 高风险 |
| `excavator` | 挖掘机靠近 | 高风险 |
| `foreign_object` | 导线异物 | 中风险 |

## 是否可以删除

不建议删除。

前端展示、后端推理、模型后处理和训练过程都需要知道类别顺序。尤其是 `classes.txt` 和 `powerline_data.yaml`，属于关键配置文件。
