# `frontend` 文件夹说明

`frontend` 是浏览器前端页面目录。

## 主要作用

- 提供输电线路智能巡检平台界面。
- 连接 Atlas 后端服务。
- 支持开发板摄像头实时流、上传图片、上传视频三种输入方式。
- 展示检测结果、风险等级、目标数量、最高置信度、推理延迟、画面帧率和告警事件。

## 当前文件

```text
frontend/
  index.html
  app.js
  styles.css
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构，包含标题、按钮、输入框、结果区域 |
| `app.js` | 前端核心逻辑，负责连接后端、上传文件、读取流式结果、刷新状态 |
| `styles.css` | 页面样式，控制布局、颜色、检测面板、按钮等 |

## 启动方式

在项目根目录运行：

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory frontend
```

浏览器打开：

```text
http://127.0.0.1:5173/
```

## 后端地址

前端默认连接：

```text
http://192.168.137.100:8000
```

如果 Atlas 开发板 IP 变化，可以在页面输入框中修改，或者使用：

```text
http://127.0.0.1:5173/?api=http://实际IP:8000
```

## 是否可以删除

如果要演示浏览器平台，不可以删除。

如果只在命令行测试模型，可以不需要该目录。
