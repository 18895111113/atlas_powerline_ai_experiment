# `src/atlas` 文件夹说明

`src/atlas` 是 Atlas 开发板端核心代码目录。

## 主要作用

- 加载 OM 模型。
- 调用 pyACL 执行 NPU 推理。
- 进行 YOLOv5 图像预处理和后处理。
- 提供 Flask 后端 API。
- 支持图片检测、视频检测、视频流式检测和摄像头实时流检测。

## 当前文件

```text
src/atlas/
  acl_runtime.py
  api_server.py
  detector_om.py
  video_infer.py
  yolo_postprocess.py
  __init__.py
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `acl_runtime.py` | pyACL 模型加载、内存申请、输入输出拷贝和推理执行 |
| `api_server.py` | Flask 后端服务，提供 `/api/health`、`/api/stream` 等接口 |
| `detector_om.py` | 将预处理、ACL 推理、后处理封装成检测器 |
| `video_infer.py` | 命令行视频/摄像头推理脚本 |
| `yolo_postprocess.py` | YOLOv5 的 letterbox、NMS、坐标还原、画框等逻辑 |
| `__init__.py` | Python 包标记文件 |

## 重要接口

`api_server.py` 提供以下接口：

| 接口 | 作用 |
|---|---|
| `/api/health` | 检查后端状态和模型加载状态 |
| `/api/detect/image` | 上传图片检测 |
| `/api/detect/video` | 上传视频离线检测 |
| `/api/detect/video/stream` | 上传视频流式检测 |
| `/api/stream` | 开发板摄像头实时检测流 |
| `/api/events` | 检测事件流 |

## 是否可以删除

不可以删除。

这是 Atlas 后端运行的核心代码。
