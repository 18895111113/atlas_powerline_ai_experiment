# `src/pc` 文件夹说明

`src/pc` 是 PC 端工具代码目录。

## 主要作用

- 检查数据集格式。
- 划分数据集。
- 调用 YOLOv5 训练。
- 导出 ONNX。
- 验证 ONNX 模型。

## 当前文件

```text
src/pc/
  check_dataset.py
  export_onnx.py
  split_dataset.py
  train_yolov5.py
  validate_onnx.py
  __init__.py
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `check_dataset.py` | 检查 YOLO 数据集图片、标签、类别编号是否正确 |
| `export_onnx.py` | 将 YOLOv5 的 `.pt` 权重导出为 `.onnx` |
| `split_dataset.py` | 数据集划分工具 |
| `train_yolov5.py` | 封装 YOLOv5 训练命令 |
| `validate_onnx.py` | 验证 ONNX 模型输入输出是否正常 |
| `__init__.py` | Python 包标记文件 |

## 常用命令

检查数据集：

```powershell
python .\src\pc\check_dataset.py --dataset-root .\datasets\powerline --num-classes 3
```

导出 ONNX：

```powershell
python .\src\pc\export_onnx.py --yolov5-dir .\yolov5 --weights .\models\best.pt --imgsz 640 --opset 12
```

## 是否可以删除

如果只运行已经部署好的 Atlas 后端，可以删除。

如果要复现训练、导出和数据检查，不建议删除。
