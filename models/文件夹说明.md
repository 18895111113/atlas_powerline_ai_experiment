# `models` 文件夹说明

`models` 是模型文件目录。

## 主要作用

- 保存训练后的 PyTorch 权重。
- 保存导出的 ONNX 模型。
- 保存或预留 Atlas OM 模型目录。

## 当前结构

```text
models/
  best.pt
  README.md
  onnx/
    best.onnx
    yolov5s.onnx
  om/
```

## 文件说明

| 文件或目录 | 作用 |
|---|---|
| `best.pt` | YOLOv5 训练得到的 PyTorch 最优权重 |
| `onnx/best.onnx` | 从 `best.pt` 导出的正式 ONNX 模型 |
| `onnx/yolov5s.onnx` | YOLOv5s 相关 ONNX 文件，可作参考或中间模型 |
| `om/` | 预留 OM 模型目录，Atlas 转换后的模型可放这里 |

## 模型转换链路

```text
best.pt
  ↓ 导出
best.onnx
  ↓ ATC 转换
powerline_yolov5s.om
```

## 是否可以删除

不建议删除。

如果删除 `best.pt`，后续不能直接重新导出 ONNX。

如果删除 `best.onnx`，后续不能直接重新转换 OM。

如果只是运行 Atlas 部署包，根目录 `models` 可以不是必需，但它对项目复现非常重要。
