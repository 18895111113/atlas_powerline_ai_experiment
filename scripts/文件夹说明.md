# `scripts` 文件夹说明

`scripts` 是项目辅助脚本目录。

## 主要作用

- 自动化训练、导出、环境检查、数据集准备和 Atlas 模型转换。
- 减少手动输入命令的错误。
- 方便复现实验流程。

## 当前文件

```text
scripts/
  atc_convert.sh
  atlas_run.sh
  check_atlas_env.sh
  pc_export.ps1
  pc_train.ps1
  prepare_powerline_dataset.py
  setup_pc.ps1
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `atc_convert.sh` | 在 Atlas/CANN 环境中将 ONNX 转换为 OM |
| `atlas_run.sh` | Atlas 端运行脚本 |
| `check_atlas_env.sh` | 检查 Atlas 环境、CANN 环境变量等 |
| `pc_export.ps1` | PC 端导出 ONNX 的 PowerShell 脚本 |
| `pc_train.ps1` | PC 端训练 YOLOv5 的 PowerShell 脚本 |
| `prepare_powerline_dataset.py` | 将原始数据整理成正式 `datasets/powerline` 数据集 |
| `setup_pc.ps1` | PC 端环境初始化脚本 |

## 是否可以删除

如果只运行已经部署好的系统，可以删除。

如果要重新训练、重新导出、重新转换 OM 或重新整理数据，不建议删除。
