# `requirements` 文件夹说明

`requirements` 用于集中保存 Python 依赖清单，避免把依赖文件直接散放在项目根目录。

## 当前文件

```text
requirements/
  pc.txt
  atlas.txt
```

## 文件作用

| 文件 | 作用 |
|---|---|
| `pc.txt` | PC 端依赖，用于数据集检查、ONNX 导出、前端辅助运行等 |
| `atlas.txt` | Atlas 端依赖，用于 Flask 后端、OpenCV 图像处理等 |

## PC 端安装

```powershell
python -m pip install -r requirements/pc.txt
```

## Atlas 端安装

```bash
python3 -m pip install -r requirements/atlas.txt
```

## 说明

根目录的 `requirements` 是开发工程使用的集中依赖目录。

Atlas 部署包 `atlas_deploy_powerline_yolov5s` 中也有自己的 `requirements` 目录，方便整个部署目录上传到开发板后独立使用。
