# `atlas_deploy_powerline_yolov5s` 文件夹说明

`atlas_deploy_powerline_yolov5s` 是项目的 Atlas 开发板部署目录。

它是从 PC 项目中整理出来、用于上传到 Atlas 200I DK A2 开发板运行的版本。

## 主要作用

- 存放 Atlas 端运行所需的后端代码。
- 存放类别文件、模型文件、转换脚本和测试视频。
- 用于在 Atlas 开发板上启动 Flask 后端服务。
- 用于运行 OM 模型推理。

## 重要子目录

```text
atlas_deploy_powerline_yolov5s/
  configs/
  models/
  scripts/
  src/
  videos/
```

## 子目录作用

| 子目录 | 作用 |
|---|---|
| `configs` | Atlas 端使用的类别文件，例如 `classes.txt` |
| `models/onnx` | 放置 ONNX 模型，供 ATC 转换使用 |
| `models/om` | 放置转换后的 OM 模型，供 NPU 推理使用 |
| `scripts` | Atlas 端转换、运行、环境检查脚本 |
| `src/atlas` | Atlas 后端、pyACL 推理、YOLO 后处理代码 |
| `src/pc` | 部分 PC 工具脚本副本，部署包中可保留作辅助 |
| `videos/input` | 测试视频输入目录 |

## 启动后端示例

在 Atlas 开发板上进入该目录：

```bash
cd /home/HwHiAiUser/atlas_deploy_powerline_yolov5s
source /usr/local/Ascend/ascend-toolkit/set_env.sh
```

启动服务：

```bash
python3 -u -m src.atlas.api_server \
  --model models/om/powerline_yolov5s.om \
  --names configs/classes.txt \
  --camera-source 0 \
  --host 0.0.0.0 \
  --port 8000
```

## 是否可以删除

如果只保留 PC 训练代码，可以删除。

如果要运行 Atlas 后端或提交一个能直接部署到开发板的项目，不建议删除。

## 和根目录 `src` 的关系

根目录 `src/atlas` 是开发版源码。

`atlas_deploy_powerline_yolov5s/src/atlas` 是上板部署副本。

修改后端逻辑时，通常需要把根目录中的改动同步到该部署目录。
