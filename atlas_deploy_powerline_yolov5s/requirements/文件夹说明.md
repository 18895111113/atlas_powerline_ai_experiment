# `requirements` 文件夹说明

该目录保存 Atlas 部署包内部使用的 Python 依赖清单。

## 当前文件

```text
requirements/
  atlas.txt
  pc.txt
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `atlas.txt` | Atlas 开发板后端运行依赖 |
| `pc.txt` | PC 端辅助脚本依赖，通常部署到开发板时不需要 |

## Atlas 端安装

在 `atlas_deploy_powerline_yolov5s` 目录中执行：

```bash
python3 -m pip install -r requirements/atlas.txt
```

## 注意

开发板真正运行后端时，一般只需要 `atlas.txt`。`pc.txt` 是为了保留部署包内脚本完整性。
